# オートクリッカー (Auto-Progress)

Windows 向けのオートクリッカーです。C++ と Win32 API だけで書かれており、追加のランタイムなしで `AutoClicker.exe` 単体で動きます。

- **連打**: 左 / 右 / 中ボタンを指定した間隔で連続クリック
- **記録・再生（マクロ）**: 実際にマウス（とキーボード）を操作して記録し、その通りに再生
- **ホットキー**: どのアプリを操作中でもキー 1 つで開始 / 停止
- **常に最前面に表示**、タスクトレイ格納、緊急停止など

## ダウンロード

GitHub の **Actions** タブ → 最新の「Build」ワークフロー → **Artifacts** の `AutoClicker-windows-x64` から exe を取得できます。
`v1.0.0` のようなタグを push すると、**Releases** にも exe が自動で添付されます。

## 機能

### 連打タブ

| 設定 | 内容 |
| --- | --- |
| 間隔 | ミリ秒 / 秒 / 分 で指定（最小 1 ms） |
| ランダム ± | 間隔を毎回ランダムに揺らす（例: 100 ms ± 20 ms → 80〜120 ms） |
| ボタン | 左 / 右 / 中 |
| 種類 | シングルクリック / ダブルクリック |
| 繰り返し | 停止するまで / 回数を指定 / 時間（秒）を指定 |
| クリックする位置 | 現在のカーソル位置 / 指定した位置（X, Y） |
| 位置を選択... | 押した後に画面上をクリックすると、その座標が入力される（そのクリックは他のアプリに渡しません。右クリックか Esc でキャンセル） |
| カーソルを元の位置に戻す | 指定位置をクリックした後、マウスカーソルを元の場所に戻す（作業しながら放置できる） |

現在のカーソル位置モードでは、誤操作防止のため **このツール自身のウィンドウの上ではクリックしません**。

### 記録・再生タブ（マクロ）

**記録する**

1. 「● 記録開始」（または `F8`）を押す
2. 実際にクリックしたりドラッグしたりする
3. もう一度 `F8`（または「■ 記録停止」）で終了 → 一覧にステップが並ぶ

- 押してすぐ離した操作は「クリック」、同じ場所で素早く 2 回押すと「ダブルクリック」、押したまま動かすと「押下 → 解放」（ドラッグ）として記録されます
- ホイール操作も記録されます
- 「マウス移動も記録」: カーソルの動きも記録します（約 15 ms ごとに間引き）
- 「キー入力も記録」: キーボード操作も記録します（このツールのウィンドウでの入力とホットキーは除外）
- 「末尾に追加して記録」: 既存のステップを残したまま後ろに追加します
- 各ステップには「前のステップからの待機時間」が記録されるので、再生すると操作したときと同じタイミングで動きます

**手動でステップを作る（指定した場所を順番にクリック）**

1. 「動作」（左クリックなど）と「待機」（例: 1000 ms）を選ぶ
2. クリックさせたい場所にマウスを置いて `F9` を押す → その位置のステップが追加される
3. 次の場所に移動して `F9`… を繰り返す

選択中のステップがある場合は、その直後に追加されます。

**編集**

- 一覧で選択 → 動作・待機・X / Y を書き換えて「変更」（入力欄で Enter でも可）
- 「位置を選択」で画面をクリックして座標を入力
- ▲ ▼ で順番の入れ替え、削除（Delete キー）、全削除、「待機を一括設定」で全ステップの待機時間を揃える
- `Ctrl+Z` で直前の編集・記録を元に戻せます（最大 30 回）
- 「開く...」「保存...」でマクロをファイル（`.acm`）に保存・読み込み

**再生**

| 設定 | 内容 |
| --- | --- |
| 繰り返し回数 | 0 で無限ループ |
| 速度 | 100 % = 記録どおり、200 % = 2 倍速、50 % = 半分の速さ |
| ループ間の待機 | 1 周ごとに入れる待ち時間 |

再生中は実行中のステップが一覧でハイライトされます。停止したときに押しっぱなしのボタン・キーは自動で離されます。

### 設定タブ

- **ホットキー**: 欄をクリックして新しいキー（Ctrl / Shift / Alt との組み合わせも可）を押し、「ホットキーを適用」
- **開始前の待機**: 開始してから実際にクリックが始まるまでの秒数（カーソルを目的の場所へ動かす時間を作れます）
- **緊急停止**: マウスをいずれかの画面の左上隅に動かすと、連打・再生を即座に止めます
- **音**: 開始・停止時にシステム音を鳴らす
- **タスクトレイに格納**: 最小化するとトレイアイコンになります（クリックで復帰、右クリックでメニュー）
- **マクロの自動保存**: 終了時に今のマクロを保存し、次回起動時に復元します

下部の「**常に最前面に表示**」はどのタブからでも切り替えられます。

## ホットキー（初期設定）

| キー | 動作 |
| --- | --- |
| `F6` | 連打の開始 / 停止 |
| `F7` | マクロ再生の開始 / 停止 |
| `F8` | 記録の開始 / 停止 |
| `F9` | 現在のカーソル位置をステップとして追加 |

ホットキーは他のアプリを操作中でも有効です。他のアプリが同じキーを使っていて登録できない場合は起動時に通知されるので、設定タブで変更してください。

## キーボードでの操作

マウスを使わずにすべての操作ができます。

| キー | 動作 |
| --- | --- |
| `Tab` / `Shift+Tab` | 項目の移動 |
| `Space` | ボタンを押す・チェックボックスの切り替え |
| `Enter` | フォーカスのあるボタンを押す（ステップ編集欄では「変更」を適用） |
| 矢印キー | ラジオボタン・一覧・ドロップダウンの選択 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab`（`Ctrl+PageDown` / `PageUp`） | タブの切り替え |
| `Ctrl+S` | マクロを上書き保存（初回は保存先を選択） |
| `Ctrl+O` | マクロを開く |
| `Ctrl+Z` | ステップの編集を元に戻す |
| `Delete`（一覧で） | 選択したステップを削除 |

## マクロファイルの形式

`.acm` はテキストファイルで、メモ帳でも編集できます。1 行が 1 ステップで、`#` で始まる行はコメントです。

```
# 種類     待機ms  引数...
CLICK      500     L 800 600 1      # ボタン(L/R/M) X Y 回数(1=シングル, 2=ダブル)
DOWN       300     L 100 200        # ボタン押下
MOVE       16      150 250          # カーソル移動
UP         20      L 200 300        # ボタン解放
WHEEL      100     800 600 -120     # X Y 量(正=上, 負=下。1 ノッチ = 120)
KEY        50      0x41 0x1E 0      # 仮想キーコード スキャンコード 拡張キー(0/1)
KEYDOWN    50      0xA0 0x2A 0
KEYUP      50      0xA0 0x2A 0
WAIT       1000                     # 待機のみ
```

座標は物理ピクセル単位の画面座標です（マルチモニターでは負の値になることもあります）。

## 設定の保存場所

`AutoClicker.exe` と同じフォルダーに `AutoClicker.ini`（設定）と `last_macro.acm`（自動保存したマクロ）を作ります。
exe を Program Files など書き込めない場所に置いた場合は `%APPDATA%\AutoClicker\` に保存します。設定タブの「フォルダーを開く」で確認できます。

## ビルド方法

必要なもの: CMake 3.15 以上と、Visual Studio 2019 以降（「C++ によるデスクトップ開発」）または MinGW-w64。

### Visual Studio

Visual Studio で「フォルダーを開く」からこのリポジトリを開くと CMake プロジェクトとして認識されます。
コマンドラインの場合（Developer PowerShell など）:

```bash
cmake -S . -B build -A x64
```

```bash
cmake --build build --config Release
```

`build/Release/AutoClicker.exe` ができます。

### MinGW-w64（Windows の MSYS2 など）

```bash
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build
```

### Linux からクロスコンパイル

```bash
sudo apt-get install g++-mingw-w64-x86-64 cmake
```

```bash
cmake -S . -B build-mingw -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64-x86_64.cmake -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build-mingw
```

## 注意事項

- **管理者権限で動いているアプリ**には、Windows の仕様（UIPI）により通常権限のこのツールからクリックやキー入力を送れません。その場合はこのツールも「管理者として実行」してください。
- オンラインゲームなどでは自動操作が利用規約で禁止されていることがあります。利用先のルールを確認してください。
- 高 DPI・マルチモニター（モニターごとに異なる拡大率）に対応しています。記録した座標は画面の物理ピクセルなので、解像度や拡大率、モニター構成を変えると位置がずれることがあります。

## ソース構成

| ファイル | 役割 |
| --- | --- |
| `src/main.cpp` | エントリーポイント（DPI 設定） |
| `src/app.cpp` | メインウィンドウ・各タブの UI・ホットキー・トレイ |
| `src/clicker.cpp` | 連打とマクロ再生のワーカースレッド |
| `src/recorder.cpp` | 低レベルフックによる操作の記録と位置選択 |
| `src/macro.cpp` | ステップのデータ構造・表示名・ファイル入出力 |
| `src/input.cpp` | `SendInput` によるマウス / キー入力の送信 |
| `src/settings.cpp` | INI ファイルへの設定の保存・読み込み |
| `src/timing.cpp` | 高精度タイマー・待機 |
| `src/worker.cpp` | 停止イベント付きのスレッド基底クラス |
| `res/` | アイコン・マニフェスト・バージョン情報 |
| `tools/make_icon.py` | アイコン生成スクリプト（Pillow が必要） |
